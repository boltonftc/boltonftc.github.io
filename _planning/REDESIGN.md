## 2. Proposed plan

### 2.1 One site-wide theme (the foundation — everything else depends on it)
- New `_layouts/site.html` sharing the landing page's nav, footer, fonts, palette and split-seam motif
  (factor nav/footer into `_includes/` so landing + site use the same markup).
- New `assets/css/site.css`: page header band, reading typography, tables, figures, callouts, step lists,
  quiz component, data tables, form controls — **no card grids**. Alternatives we'll use instead:
  numbered index lists with big League Gothic numerals, rule-separated rows, spec-sheet tables,
  two-column "label | content" layouts, chamfered rails.
- `_config.yml`: rebrand title/description, default `layout: site` for all pages, simplified nav
  (Mechanical · Electrical · Programming · Calendar), drop `remote_theme` once every page renders on `site`.
- Reading pages use a **light "paper" content surface (#F4F4EE) inside the dark navy chrome** (see Q2).

### 2.2 Calendar (`/calendar/`, replaces `/schedule/`)
- Single source of truth: `assets/data/calendar.json`
  - `recurring`: Wed 3:00–5:30 PM and Sun 6:30–8:30 PM, start → end date
  - `skip`: holiday/break dates (with a reason, shown as "No meeting — Veterans Day")
  - `events`: one-offs (scrimmages, competitions, outreach, build days) with optional location/link/notes
  - optional `notes` link per date → that week's meeting page
- `tools/build_calendar.py` expands the rules and writes **`assets/calendar/prime-symmetry.ics`** so families
  can **subscribe** in Google/Apple/Outlook (updates flow automatically).
- Page: "Next meeting" countdown strip + agenda timeline (grouped by month) + month grid toggle;
  holidays shown as struck-through dates; past meetings link to their notes.
- Future updates = "add these events" → I edit the JSON + rerun the script.
- Meetings index restyled as a **timeline** (no cards) and linked from the calendar.

### 2.3 Electrical (`/electrical/`)
- Hub: short intro + the two lessons as a numbered index (01 Electrical Systems, 02 Electrical Gremlins)
  + "Reference" list (REV docs, FIRST wiring guide, ESD guide/analysis, Robot Configuration page) moved in from Resources.
- Lessons re-flowed into the new reading layout; tier badges/paths removed; move to
  `/electrical/systems/` and `/electrical/gremlins/` with redirects from old URLs.
- **End-of-lesson quiz** (no tracking): shared `assets/js/quiz.js` + per-lesson JSON using the simulator schema;
  ~12 questions, draw 8, balanced answer lengths (correct ≠ longest).

### 2.4 Mechanical (`/mechanical/`)
- Hub: lessons index (Robot Hardware + CAD Training 1–6), **Belt Tools feature band** (live mini-diagram +
  "Wizard / Find Belt / Center Distance"), goBILDA RI3D parts lists, reference links moved from Resources
  (goBILDA docs, mechanism encyclopedia, fastener charts, Brogan Pratt, OnShape EDU, FTC parts library).
- Robot Hardware lesson re-flowed + quiz. CAD lessons re-skinned (content unchanged). RI3D pages re-skinned
  (spec-sheet tables, consistent nav between sub-assemblies).
- Belt tools move to `/mechanical/belt-tools/` (redirect from `/resources/belt-calculator/`), re-skinned;
  hub becomes an index, not cards.

### 2.5 Programming (`/programming/`)
- Hub = "Learn to program in the Impulse 3D Simulator": the **17-lesson track** listed with
  **deep links straight into each lesson in the sim** (requires a small sim change: `?lesson=<id>`),
  Deploy-to-Robot (USB) tool featured, Driver Controls, external programming links from Resources
  (Pedro Pathing, OTOS setup/tuning, gm0 software, FTC docs, Javadoc).
- Retire the 20 old Godot-era lesson pages (redirect each to `/programming/`).
- `/simulator/` → becomes the simulator's "about / for coaches" page or redirects (see Q6).

### 2.6 Resources (`/resources/`) — slim "Team Toolkit"
- Featured: **Inventory** (searchable spend tracker) and **Season Budget**.
- Team tools: Laptop Setup, Rules Quiz, Robot Configuration, Driver Controls (each also cross-linked from its discipline page).
- "Start here" essentials only: Game Manual, gm0, Inspection Reference, FTC Survival Guide, Hivemind portfolios.
- Discipline links move to Mechanical / Electrical / Programming.

### 2.7 Inventory re-skin
- `tools/rebuild_inventory.py` writes **`assets/data/inventory.json`** (instead of 1,971 lines of HTML).
- New page: big totals header (total spend, # line items, vendors), **spend-by-category bar strip**,
  instant search, category + vendor filters, sortable columns, compact rows, links to SKUs.
- "How we track it" blurb (receipts → script → page) to showcase the process.

### 2.8 Everything else (consistency pass)
- Meetings (index + week pages), Practice Game, Use & Attribution, Laptop Setup, Season Budget, Rules Quiz
  (migrated to shared quiz engine), Driver Controls, Robot Config → all on `site` layout, cards removed.
- Fix stale references (Bolton Robotics FTC → Prime Symmetry; Godot PIT Mode links).

### 2.9 Verification
- Local preview tool upgraded to render any page (layouts + includes + `site.data`), plus a link checker
  across the whole site (no 404s, every redirect lands).
- You review each phase in the browser before push.
