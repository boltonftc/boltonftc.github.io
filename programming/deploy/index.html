Built an OpMode in the 3D Simulator and want it on the real bot? Plug the Control Hub into this computer with a USB cable, then use the buttons below. Everything runs in your browser — there is nothing to install.

You need: Google Chrome or Microsoft Edge · a USB cable to the Control Hub · the Hub powered on. (Safari and Firefox can’t talk to USB devices — use Chrome/Edge.)
1Connect
Pick the Control Hub in the browser prompt.
2Choose code
Select your teamcode folder.
3Deploy
Push the files and build on the robot.
